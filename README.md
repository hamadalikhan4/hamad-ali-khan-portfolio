# Hamad Ali Khan - Portfolio

A responsive GitHub Pages portfolio focused on cybersecurity and web development, with UI/UX design presented as an additional strength.

## Project files

- `index.html` - portfolio content and page structure
- `styles.css` - complete dark responsive design
- `script.js` - mobile navigation, active sections, and reveal animations
- `assets/Hamad-Ali-Khan-CV.pdf` - downloadable CV

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository named `hamad-ali-khan-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, `README.md`, and the complete `assets` folder to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** under **Code and automation**.
5. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
6. Choose the `main` branch and `/(root)` folder, then click **Save**.
7. After deployment, the site should be available at:

   `https://hamadalikhan4.github.io/hamad-ali-khan-portfolio/`

GitHub may take several minutes to publish the first version.

## Customize before publishing

- Confirm the LinkedIn URL in `index.html`.
- Add direct repository links to each project when they are available.
- Replace the HAK monogram with a professional portrait later if preferred.
- Keep private phone and identity numbers out of this public repository.

## Preview locally

Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.
